# Dataset dan sample input

Folder ini hanya boleh berisi sample atau dataset yang sumber, lisensi, dan cara perolehannya terdokumentasi. Data privat, bocoran, dan footage kamera yang dapat mengenali individu tidak boleh disimpan di repository.

Untuk evaluasi lokal, sample sintetis atau sample berlisensi akan ditempatkan di `dataset/mock/` dan dijelaskan di dokumen metadata terpisah. Jangan menyamarkan data sintetis sebagai rekaman cafe nyata.

Fixture yang tersedia:

- `mock/workspace.ppm` — frame sintetis 32×18 piksel dengan empat area meja berwarna. File ini dibuat khusus untuk pengujian pipeline lokal, bukan rekaman cafe nyata dan tidak mengandung wajah atau data pribadi.
